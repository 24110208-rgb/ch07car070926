# Dự án Java Web - ch07car070926

Đây là bài tập/dự án môn Lập trình Web (LTWED) được phát triển bằng ngôn ngữ Java.

## 🛠️ Công nghệ sử dụng
* **Ngôn ngữ:** Java
* **Công nghệ Web:** Servlet, JSP
* **Công cụ quản lý:** Ant (file `build.xml`)
* **Môi trường khuyến nghị:** NetBeans IDE / Eclipse / IntelliJ IDEA

## 📂 Cấu trúc thư mục chính
* `src/`: Chứa mã nguồn Java (Controllers, Models, Daos...)
* `web/`: Chứa giao diện frontend (HTML, CSS, JS, các file JSP)
* `nbproject/`: Cấu hình dự án của NetBeans IDE

## 🚀 Hướng dẫn cài đặt và chạy dự án
1. **Tải mã nguồn:** Cài đặt Git và clone dự án hoặc tải file ZIP về máy.
2. **Mở dự án:** Sử dụng **NetBeans IDE** mở thư mục `ch07car070926`.
3. **Cấu hình Server:** Kết nối dự án với Apache Tomcat hoặc GlassFish Server trong IDE.
4. **Chạy dự án:** Nhấp chuột phải vào dự án chọn **Clean and Build**, sau đó chọn **Run**.
